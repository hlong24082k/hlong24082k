## 👋 About Me

I'm an AI Engineer based in Vietnam with 3+ years of experience building AI applications. I work across the stack, from multi-agent systems and LLM-powered workflows to the web apps, databases, and deployments that put them in front of users.

## 🚀 Featured Projects

**🌐 NaturalLanguage2Web Platform**
A multi-agent system that turns natural-language requirements into complete full-stack websites, each with its own database and independent deployment. Supports iterative changes and new features after generation.

**🧪 Tester Agent Platform**
Takes specifications and test documents, then automatically generates test cases, test data, and Playwright scripts, runs the tests, and reports the results.

**📊 CRM for Small Businesses**
A full-stack CRM for managing cash flow, inventory, and role-based permissions, with dedicated roles and business functions per employee. Owned full-stack development, deployment, and monitoring.
